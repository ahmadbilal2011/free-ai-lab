# Lesson 08 — n8n: the engine behind every Jarvis skill

**Goal:** install **n8n** on the server, connect it to Jarvis's brain (the gateway), and build your first two workflows. Every Jarvis skill from now on (Telegram, voice, reminders, PC jobs, cloud tools) is an n8n workflow.

**Time:** about 30–40 minutes.

**Cost:** $0. n8n is free to self-host for personal use.

**Before you start:** Lessons 04 (Tailscale), 06 (gateway) and ideally 07 (backups) are done.

---

## Part A — What n8n is, and why it's Jarvis's core

**n8n** ("n-eight-n") builds automations from **nodes** connected on a canvas: "when *this* happens, do *that*, then *that*".

```
 [Trigger] ──► [Node] ──► [Node] ──► [Node]
 "a Telegram    "ask the    "is it a     "reply on
  message"       brain"      PC job?"     Telegram"
```

| Why n8n | Detail |
|---|---|
| **Light on the server** | n8n only *coordinates*; the thinking happens in free cloud models through the gateway |
| **Hundreds of connectors** | Telegram, Google (Calendar, Tasks, Gmail), Microsoft, HTTP requests… mostly no code |
| **AI built in** | Chat models, AI Agents with tools, memory (Lesson 16) |
| **Visual** | You see every step and its data: easy to learn and debug |
| **Your data stays here** | Workflows and credentials live on your server, encrypted, backed up nightly |

> **Licence:** n8n is "fair-code" (Sustainable Use License): **free to self-host for personal and internal use**, which is our case. You just can't resell it as a service.

### Core words

| Word | Meaning |
|---|---|
| **Workflow** | One automation: a chain of nodes |
| **Trigger** | The node that starts it: a schedule, a manual click, a message… |
| **Node** | One step: "call AI", "send message", "if / else", "HTTP request" |
| **Credential** | A saved login or key that nodes use. n8n **encrypts** these |
| **Execution** | One run of a workflow, with the data at every step |
| **Published** | Switched on, so its trigger runs by itself (n8n 1.x called this "Active") |
| **Expression** | `{{ … }}`: use data from earlier steps, e.g. `{{ $json.text }}` |

## Part B — How it fits in

```
Laptop / phone ──Tailscale HTTPS──► https://free-ai-lab.<tailnet>.ts.net:9443 ──► n8n (127.0.0.1:5678)
                                                                                      │
                                         workflows call the brain:  http://litellm:4000/v1
                                                                    (smart / fast / private)
```

Choices in [`stacks/jarvis/compose.yaml`](../stacks/jarvis/compose.yaml):

| Setting | Why |
|---|---|
| Built-in **SQLite** (no Postgres) | One less container; plenty for one person |
| `127.0.0.1:5678` + Tailscale `:9443` | Editor is private. Tailscale Funnel can't publish 9443, so it can never go public by mistake |
| Joins the `jarvis` network | Workflows reach the gateway as `http://litellm:4000/v1` |
| `N8N_ENCRYPTION_KEY` in `.env` | Encrypts saved credentials. **Lose it and every saved credential is unreadable** |
| `mem_limit: 1g` | n8n can never eat the private model's memory |
| Successful runs not saved, failures kept 14 days | Telegram polling (Lesson 09) runs thousands of times a day; only problems are worth keeping |
| No telemetry | Nothing sent to n8n's company |
| Healthcheck + autoheal | A frozen n8n restarts by itself |
| Data in `~/lab/jarvis/n8n` | In the nightly backup; paused a few seconds at 03:30 for a clean copy |

## Part C — Install (one command)

On the server, as `ubuntu`, **without** `sudo` in front:

```bash
curl -fsSL https://raw.githubusercontent.com/ahmadbilal2011/free-ai-lab/main/scripts/08-install-n8n.sh -o 08-install-n8n.sh && bash 08-install-n8n.sh
```

It:

1. checks Docker, the gateway and Tailscale;
2. creates `~/lab/jarvis` with a private `.env` (random **encryption key**, your Tailscale name, your time zone);
3. starts n8n and checks it can reach the gateway;
4. publishes the editor at **`https://free-ai-lab.<your-tailnet>.ts.net:9443`** (tailnet only);
5. checks it's in the nightly backup;
6. **shows the encryption key once**: save it in your password manager.

Then open that address on your laptop (Tailscale on) and **create the owner account right away**: the first person to open a new n8n becomes its owner.

Source: [`scripts/08-install-n8n.sh`](../scripts/08-install-n8n.sh)

## Part D — Connect n8n to Jarvis's brain

n8n's AI nodes speak the same request format as our gateway, so we use n8n's **OpenAI** credential type but point it at **our gateway**. No OpenAI account is involved.

1. On the server, show the gateway's master key (paste it **only** into n8n):
   ```bash
   grep LITELLM_MASTER_KEY ~/lab/brain/.env
   ```
2. In n8n: **Overview → Credentials → Create credential** → search **OpenAI** → fill in:

   | Field | Value |
   |---|---|
   | API Key | the `sk-…` master key |
   | Base URL | `http://litellm:4000/v1` |
   | Organization ID | leave empty |

3. Name it **`Jarvis brain`** → **Save**. "Connection tested successfully" means n8n can reach the gateway.
4. Type `clear` on the server so the key isn't left on screen.

From now on, every AI node uses `Jarvis brain` and picks `smart`, `fast` or `private`.

## Part E — Workflow 1: "Hello Jarvis" (manual)

1. **Create workflow** → name it `Hello Jarvis`.
2. **Add first step** → **Trigger manually**.
3. **+** → **Basic LLM Chain**:
   - **Source for Prompt:** *Define below*
   - **Prompt:** `You are Jarvis, my personal assistant. Greet me in one short sentence and suggest one small thing I could automate in my day.`
4. On the chain's **Model** connector (bottom) → **+** → **OpenAI Chat Model**:
   - **Credential:** `Jarvis brain`
   - **Model:** `smart` (or *By ID* → type `smart`)
5. **Execute workflow**.

Click the chain node to see its **input**, **output** and the answer: Jarvis's first reply from n8n. Then switch the model to `fast` and `private` and compare speed and quality.

## Part F — Workflow 2: a scheduled job

A workflow that runs **by itself**:

1. Create `Hourly tip (practice)`.
2. Trigger: **On a schedule** → **Every hour**.
3. **Basic LLM Chain** with model `fast` and the prompt: `Give one short, practical Linux command tip with an example. Max 2 sentences.`
4. Save → click **Publish** (top right). In n8n 2.x, "Publish" switches a workflow on; older guides call it "Active".
5. A bit later, open **Executions**. (Successful runs aren't stored, so to see one, open the workflow and click **Execute workflow**; you'll see the full data there.)
6. **Unpublish** it when you've seen it work: no free-tier requests wasted on practice. In Lesson 09 a workflow like this messages you on Telegram instead.

### What you just learned

| Idea | Where |
|---|---|
| Triggers: manual vs schedule | Workflows 1 and 2 |
| Credentials: saved once, reused, encrypted | `Jarvis brain` |
| Gateway aliases from any workflow | `smart` / `fast` / `private` |
| Published vs not | Workflow 2 |

## If something goes wrong

| Problem | Fix |
|---|---|
| `The 'jarvis' network is missing` | Do Lesson 06 first |
| Editor doesn't load | Tailscale on? Note the **`:9443`**. `docker ps` should show `n8n (healthy)`. HTTPS certificates on in the Tailscale admin (Lesson 04, Part D)? |
| Browser warns about the certificate on first visit | Wait a minute and reload: Tailscale fetches the certificate on first use |
| `EACCES` / `permission denied` in `docker logs n8n` | `sudo chown -R 1000:1000 ~/lab/jarvis/n8n && docker restart n8n` |
| Credential test fails | Base URL exactly `http://litellm:4000/v1`; the key is the **master** key from `~/lab/brain/.env`; `docker ps` shows `litellm (healthy)` |
| Model list is empty | Choose **By ID** and type `smart` |
| Schedules run at the wrong hour | The time zone is wrong: `TZ_NAME=Asia/Riyadh bash 08-install-n8n.sh` (any `Area/City` name works) |
| I pasted the encryption key somewhere (a chat, a screenshot) | If no credentials are saved yet, start n8n fresh with a new key: `cd ~/lab/jarvis && docker compose down && sudo rm -rf n8n .env && cd ~ && bash 08-install-n8n.sh`. Later on, treat it like any leaked secret: also replace every credential saved in n8n |
| `Mismatching encryption keys` | The key in `~/lab/jarvis/.env` changed. Put back the one from your password manager |
| n8n restarts often | `docker logs n8n`. If it's out of memory, raise `mem_limit` to `1536m` in `~/lab/jarvis/compose.yaml` and `docker compose up -d` there |
